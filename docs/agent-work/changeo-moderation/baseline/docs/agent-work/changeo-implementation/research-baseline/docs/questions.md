Specify permitted/prohibited/regulated services, individual/business eligibility, local/remote/shipped fulfillment coverage, supported collection and settlement methods, currencies and onboarding conditions. Identify the responsible issuer/payer, exact required presentation and applicable rights/exceptions with professional review; a processor receipt alone is not fiscal-invoice evidence.
