Identity owns persisted facts, locks, tokens, factors and append-only audit. [IdentityAccess](../../../../src/main/java/ar/changeo/identity/api/IdentityAccess.java) exports immutable request/decision/snapshot contracts without JPA state. The [permission owner](../../../../src/main/java/ar/changeo/identity/PermissionService.java:28) rejects absent caller transactions and marks denied protected transactions for rollback. [Sorted account locking](../../../../src/main/java/ar/changeo/identity/IdentityStore.java:31) includes discovered current guardian accounts even for minor self-drafts; changed relationships deny without adding out-of-order locks. Native PostgreSQL row locks precede JPA refresh, then relationship/consent locks and current facts. Later owners must add their own resource membership, moderation, terms, KYC/billing and money checks in the same protected commit. Prospective payer exists only for agreement/funding eligibility and transfers no historical rights.

[Token consumption](../../../../src/main/java/ar/changeo/identity/AccountService.java:98) serializes account before token, checks hash/purpose/owner/generation/expiry/single-use and applies the intended effect atomically. Recovery advances epochs/generations and preserves MFA. Private filesystem delivery never exposes an HTTP inbox or token URL; failure stays pending with generic anonymous recovery acknowledgment. Current security epochs invalidate old ordinary and MFA sessions on each request. Guardian history and consent references are terminal/immutable; new relationships require new consent.

Unique operator factors are deliberately provisioned through a non-listening CLI, encrypted using AES-GCM with an external owner-private key. The web verifies enrolled TOTP only; no role/factor self-grant endpoint exists. Persisted counters reject concurrent/restart replay. MFA rotates session IDs, expires after ten minutes and combines with current role plus fresh password for security actions. Missing/invalid/wrong keys with enrolled factors fail startup before server availability. Effective public/ambiguous binds, extra production profiles and any live-money enablement fail closed.
