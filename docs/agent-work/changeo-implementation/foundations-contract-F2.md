# Shared foundation contract F2: accepted sandbox refinements

Root accepts docs/agent-work/changeo-foundations/design-amendment-F2.md under S1, superseding F1 where amended. Independent plan review remains required before product development. Five recorded findings refine authorization concurrency, administrator-factor lifecycle, tokens/sessions, capability/context/payer semantics and guardian/consent transitions; they do not approve production policies or expand money ownership.

Advisory `decide`/snapshots cannot authorize a later protected write. `requireForUpdate` requires an already-active resource-owner transaction and retains identity-owned deterministic stable-account/relationship/consent locks through its protected commit. Conflicting identity mutations use the same order. A denied or absent-transaction guard rolls back; external/asynchronous money owners still need their own revalidation and reconciliation. Every future feature consuming F2 must follow this contract, not cache a permission result.

Actor identity comes from the trusted server security context. Root accepts the coordinator's explicit clarified `PermissionRequest(Optional<ActorId>, Optional<SubjectId>, Capability, Optional<JobContext>)`: both account IDs present for authenticated requests, both absent only for anonymous BROWSE_GENERAL/VIEW_SENSITIVE, mismatched presence denied. Never forge an anonymous account or trust a client-supplied actor. Protected mutations reject anonymous/unknown identities. Sensitive/adult access still requires content owner's classification/approval and documented audience controls.

Root also accepts the lock-set clarification: discover and lock the current guardian account even for minor self-drafts; establish the complete sorted account set first, then reload/validate relationship state. If the relationship or required account set changed, deny or retry in a fresh transaction; never append new locks out of order. Same plan reviewer verifies both clarifications before readiness.

Prospective payer is optional and limited to new agreement/synthetic funding eligibility. It never changes historical job/credit ownership. Controlled retained-rights access is separately checked against historical resources; guardian relinking does not transfer another payer's rights. Identity owns consent evidence; actual job owner validates resource/participants/mode in its transaction.

Synthetic administrator provisioning is local opt-in with unique generated factors and owner-private enrollment material; no password-only web factor enrollment/replacement, shared credentials or production recovery policy. Encrypted factors use an explicit external private key and fail closed on key failure; atomic persisted TOTP replay protection and epoch-bound session/fresh-auth rules are required. Account/purpose/generation-bound token consumption and security-epoch invalidation are transactional; local mailbox and secrets never become public HTTP content or general logs.

One pending/verified guardian link per synthetic minor is accepted as this sandbox feature's supported cardinality, not as a professional determination of production guardian arrangements. Pending verification, distinct adult/relationship/minor evidence, terminal revoke/reject, fresh link generation and new per-job consent preserve the original guardian controls. Any production/multiple-authority policy remains subject to documented legal/user requirements and later approved contract revision. No ordinary under-16 provider workflow; 16–17 remains fail-closed without explicit synthetic legal/partner evidence in this development scope.

Acceptance adds real PostgreSQL concurrency/rollback, token/epoch/replay, restricted-rights, guardian generation and effective listener/money-mode tests. Missing runtime/Testcontainers/browser support remains honest missing verification. Root accepts routine technical synthetic security timings in F2 without selecting production retention/commercial values. Same plan reviewer resolves readiness, same eventual sole builder implements, and distinct final reviewer alone accepts feature behavior. A further material shared design amendment returns to root.
